# Step 1: Initial Assessment

## Objective
Capture and validate the initial problem statement to ensure clarity and completeness before decomposition.

## Context
This is the first step in the problem statement decomposition workflow. A well-defined problem statement is essential for effective analysis and solution development.

## Instructions

### For AI Agents
1. Read the provided problem statement
2. Analyze the statement for clarity, completeness, and specificity
3. Identify any ambiguities or missing information
4. Document the validated problem statement
5. Proceed to the next step with the refined statement

### For Human Analysts
1. Write down or paste the problem statement you want to analyze
2. Review it for:
   - Clarity: Is the problem clearly articulated?
   - Specificity: Are there concrete details?
   - Scope: Is the scope well-defined?
   - Measurability: Can success be measured?
3. Refine the statement as needed
4. Document any initial observations or questions

## Input Requirements
- **Problem Statement**: The original problem or challenge to be analyzed
- **Context Information**: Any background or situational context
- **Success Criteria**: How will we know when the problem is solved?

## Output Deliverables

### Validated Problem Statement
```
[Document the refined, validated problem statement here]
```

### Initial Observations
```
[Note any immediate observations, questions, or concerns]
```

### Scope Boundaries
```
What is IN scope:
- [Item 1]
- [Item 2]

What is OUT of scope:
- [Item 1]
- [Item 2]
```

## Quality Checklist
- [ ] Problem statement is clear and unambiguous
- [ ] Key terms are defined or understood
- [ ] Scope is explicitly stated
- [ ] Success criteria are identified
- [ ] Any critical assumptions are noted
