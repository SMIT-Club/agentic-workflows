# Step 5: Synthesis

## Objective
Synthesize all findings from previous steps into a comprehensive analysis with actionable insights and recommendations.

## Context
This final step brings together the problem assessment, stakeholder perspectives, component breakdown, and constraints analysis into a cohesive framework for decision-making.

## Instructions

### For AI Agents
1. Review all outputs from Steps 1-4
2. Identify patterns, themes, and critical insights
3. Prioritize problem components based on impact and feasibility
4. Develop actionable recommendations
5. Create a summary document for stakeholders

### For Human Analysts
1. Review your work from all previous steps
2. Look for connections and patterns across the analysis
3. Identify the highest-priority areas for action
4. Develop specific, actionable recommendations
5. Prepare findings for presentation to stakeholders

## Input Requirements
- **Validated Problem Statement** (Step 1)
- **Stakeholder Analysis** (Step 2)
- **Problem Breakdown** (Step 3)
- **Constraints Analysis** (Step 4)
